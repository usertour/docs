## Technical Requirements

### Internet Connection

> **Note**: Usertour requires an active internet connection to function.

Usertour is a cloud-based solution that needs internet connectivity to:
- Load and display user experiences
- Track user interactions
- Update content in real-time
- Sync user data

### Deployment Options

#### Cloud Hosting (Recommended)
- ✅ Fully managed cloud service
- ✅ Automatic updates
- ✅ Built-in analytics
- ✅ Zero maintenance
- ✅ Enterprise-grade support

#### Self-Hosted
- ✅ Free for production and commercial use (Community Edition, MIT)
- ⚠️ [Business/Enterprise features](/open-source/business-enterprise) require a license
- ✅ Complete data control
- ✅ Custom deployment options
- ✅ Private network support
- ✅ Custom domain support

## Accounts & Projects

### Is there a limit on the number of projects?

No. A project is one application in Usertour, and an account can belong to any number of projects on any plan. Each project has its own subscription. See [Projects](/how-to-guides/projects) for how to add a project for a second application and switch between projects.

### Can I use one project for several applications?

We recommend one project per application. Content, themes, attributes, end users and team members are all scoped to a project, so keeping applications in separate projects keeps their data apart. Environments are for the development, staging and production setups of a *single* application, not for separating applications. See [Projects vs. environments](/how-to-guides/projects#projects-vs-environments).
